# AQUACAST v3.2 — Manual Flagging

- Administrator-only **Action** column in Consumption Records.
- Flag an unflagged station/month reading and provide a required reason.
- Manual flags join existing Anomaly Monitoring, investigation and archive workflow.
- Previously flagged readings offer **View flag** instead of duplicate creation.
- Manual flags persist in localStorage and synchronize across same-origin tabs (v3.1 mechanism).
- Record status filters, dashboard and reports reflect manual flags.
- Prototype only: browser storage, not secure cross-device persistence.
