# AQUACAST v3.9.2 — Consumption Records sorting and filtering

- Added Report-style year and month filters, station selector, and a Sort by menu.
- Sort by newest/oldest period, station A–Z/Z–A, and highest/lowest consumption.
- Existing search and flagged/normal filters work together with the new selectors.
- Sortable table headers stay synchronized with the sort menu.
- Reset filters clears every selection and returns to newest-first sorting.
- Refreshes filter options when imported data changes; respects station role scoping.
- Updated service-worker cache version.
